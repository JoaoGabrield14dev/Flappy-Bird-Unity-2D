# 🐦 Flappy Bird - Unity

A recreation of the classic **Flappy Bird** game, developed using Unity. This project was created for learning and educational purposes, allowing developers to explore how a simple 2D game can be built using Unity.

The repository includes the complete Unity project files and a playable build, so you can both experience the game and explore its implementation.

## 🎮 About the Project

The goal of this project is to recreate the core gameplay mechanics of Flappy Bird while sharing the development files with the community.

You can explore the scripts, scenes, assets, and other project files to understand how the game works and use them as a reference for your own Unity learning projects.

## 🛠️ Technologies

- **Engine:** Unity 6.5
- **Language:** C#
- **Input:** Unity Input System
- **Game Type:** 2D

## 📋 Requirements

To open and run the Unity project, make sure you have:

- **Unity 6.0 or later** (Unity 6+).
- **Input System package** installed and enabled.
- A compatible version of Unity Hub.

### Dependencies

This project uses the **Unity Input System** package for handling player input.

Make sure the Input System is installed through the Unity Package Manager and enabled in the project settings.

To enable it:

1. Open the project in Unity.
2. Go to `Edit > Project Settings > Player`.
3. Find `Active Input Handling`.
4. Select `Input System Package (New)`.

If prompted, restart the Unity Editor.

## 📂 Project Contents

The repository contains:

- **Unity Project:** Complete project files, including scenes, scripts, assets, and configurations.
- **Build:** A compiled version of the game, ready to play.

## 🚀 Getting Started

### Playing the Game

1. Go to the [Releases](../../releases) section.
2. Download the latest available build.
3. Extract the downloaded files.
4. Run the game executable.

### Opening the Unity Project

1. Clone or download this repository.
2. Open Unity Hub.
3. Click `Add Project` and select the downloaded project folder.
4. Open the project using Unity 6 or later.
5. Make sure the Input System package is installed and enabled.
